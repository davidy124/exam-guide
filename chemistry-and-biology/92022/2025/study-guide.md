## Core Vocabulary — Must Know Precisely

> 📝 **Tested in:** [Q1(a)](exam.md#q1a) · [Q1(b)(i)](exam.md#q1bi) · [Q1(b)(ii)](exam.md#q1bii) · [Q2(a)(i)](exam.md#q2ai) · [Q3(a)](exam.md#q3a) · [Q3(b)](exam.md#q3b)

> **The #1 reason candidates lose marks: using "gene" and "allele" interchangeably.** These are different things. So are "genotype" and "phenotype".

| Term | Precise Definition | Common Mistake |
|---|---|---|
| **DNA** | Large double-helix molecule made of sugar, phosphate, and bases (A–T, G–C pairs) | Saying DNA "is" a chromosome |
| **Chromosome** | Long strand of tightly wound DNA; humans have 46 (23 pairs) | Confusing chromosome with gene |
| **Gene** | A specific section of a DNA sequence that codes for a specific trait | Using "gene" when you mean "allele" |
| **Allele** | A different version of the same gene | Using "allele" when you mean "gene" |
| **Genotype** | The allele combination for a specific trait at a locus (e.g. FF, Ff, ff) | Confusing with phenotype |
| **Phenotype** | The physical/observable expression of the genotype (influenced by environment) | Confusing with genotype |
| **Mutation** | A permanent base change in the sequence of a DNA strand | Saying mutation = allele |
| **Heritable variation** | Variation that can be passed to offspring — mutation occurred in a gamete/sex cell | Confusing with non-heritable |
| **Non-heritable variation** | Variation from environmental effects on somatic cells; cannot be passed on | Thinking all mutations are heritable |
| **Dominant** | An allele whose trait is expressed even with only one copy (F) | |
| **Recessive** | An allele whose trait is only expressed when homozygous (f) | |
| **Homozygous** | Two identical alleles at a locus (FF or ff) | |
| **Heterozygous** | Two different alleles at a locus (Ff) — also called a carrier | |
| **Carrier** | A heterozygous individual (Ff): unaffected, but can pass on the f allele | |
| **Locus** | The specific location of a gene on a chromosome | |
| **Gamete** | A sex cell (sperm or egg) — haploid, carries one allele per locus | |
| **Population** | A group of individuals of the same species in the same area (capable of interbreeding) | |
| **Gene pool** | All the alleles present in a population | |
| **Allele frequency** | How common a particular allele is in a population | |

## CFTR Gene — Context Facts

> 📝 **Tested in:** [Q1(b)(i)](exam.md#q1bi) · [Q1(b)(ii)](exam.md#q1bii) · [Q2(a)(i)](exam.md#q2ai) · [Q2(a)(ii)](exam.md#q2aii)

- CFTR = cystic fibrosis transmembrane conductance regulator
- Located on **chromosome 7**
- Controls mucus production in the human body
- **Normal allele: F** (dominant) | **Mutant allele: f** (recessive)

| Genotype | Phenotype |
|---|---|
| FF | Normal mucus production (unaffected) |
| Ff | Normal mucus production (unaffected — **carrier**) |
| ff | Excessive mucus production = **cystic fibrosis** |

> The original F→f mutation **must have occurred in a gametic cell** — because it has been passed across many generations. A somatic mutation would be non-heritable.

## Question One, Part A — DNA → Chromosome → Gene → Allele

> 📝 **Tested in:** [Q1(a)](exam.md#q1a)
> **Also see:** [Core Vocabulary](study-guide.md#sg-vocab) · [Common Mistakes](study-guide.md#sg-mistakes)

### The Hierarchy

```
DNA
 └─ wound tightly → Chromosome
                      └─ specific section → Gene  (codes for one trait)
                                              └─ different version → Allele
```

**Key relationships to explain:**
- Chromosomes are made of DNA
- Genes are specific sections of DNA on a chromosome
- Alleles are variants of the same gene at the same locus
- Different alleles cause variation in phenotype

**CFTR example linking all four:**
> Chromosome 7 is a long strand of DNA. A specific section of chromosome 7 is the CFTR gene. The base sequence of this gene produces the normal allele (F). A slight change in the base sequence produces a different version of the gene — the mutant allele (f).

**Grade tips:**
- **Achievement:** Define each of the four terms correctly
- **Merit:** *Explain the relationship* between them using examples — don't just list definitions
- **Excellence:** Use a flowing, linked explanation; examples don't have to be CFTR (blood groups, eye colour etc. are valid)

## Question One, Part B — Mutation, Phenotype/Genotype, Heritable/Non-heritable

> 📝 **Tested in:** [Q1(b)(i)](exam.md#q1bi) · [Q1(b)(ii)](exam.md#q1bii)
> **Also see:** [Core Vocabulary](study-guide.md#sg-vocab) · [CFTR Context](study-guide.md#sg-cftr) · [Common Mistakes](study-guide.md#sg-mistakes)

### Mutation
- A **permanent** base change in the sequence of a DNA strand
- For CFTR: a change in the F allele's base sequence produced the f allele

### Genotype vs Phenotype
| | Definition | CFTR Example |
|---|---|---|
| **Genotype** | Allele combination at a locus | FF, Ff, or ff |
| **Phenotype** | Observable expression of the genotype | Normal mucus / cystic fibrosis |

Key point: FF and Ff have **different genotypes but the same phenotype** — dominance means F masks f.

### Heritable vs Non-heritable Variation
| | Where mutation occurs | Can be inherited? | CFTR link |
|---|---|---|---|
| **Heritable** | Gamete (sex cell) | Yes — passed to offspring | The F→f mutation was gametic |
| **Non-heritable** | Somatic (body) cell | No — stays with that individual | Would not appear in pedigree |

### Somatic vs Gametic Mutation (Merit/Excellence)
- The CFTR mutation must have been **gametic** — it has persisted across many generations in the population
- A somatic mutation would not appear in a family pedigree at all

**Grade tips:**
- **Achievement:** Define mutation, phenotype, genotype, genetic variation, heritable OR non-heritable
- **Merit:** Explain the difference with clear examples; explain somatic vs gametic distinction
- **Excellence:** Link all concepts in a continuous causal explanation within the CFTR context; must state the F→f mutation occurred in a gametic cell

## Question Two, Part A — Reading Pedigree Charts

> 📝 **Tested in:** [Q2(a)(i)](exam.md#q2ai) · [Q2(a)(ii)](exam.md#q2aii) · [Q2(b)](exam.md#q2b) · [Q2(c)](exam.md#q2c)

### Pedigree Symbols
- □ = unaffected male | ○ = unaffected female
- ■ = affected male | ● = affected female
- Horizontal line = mating pair | Vertical line = offspring

### Rules for Working Out Genotypes

| Observation | Conclusion |
|---|---|
| Individual is affected (ff phenotype) | Genotype is **ff** |
| Unaffected individual has an affected child | Must be **Ff** (carrier) |
| Two unaffected parents have an affected child | Both parents must be **Ff** |
| Unaffected individual, no affected offspring yet | Could be **FF or Ff** — cannot confirm |

> ⚠️ **Never write a single allele.** Genotypes always have TWO alleles: FF, Ff, or ff — never just F or f.

### This Pedigree — All Genotypes

| Individual | Genotype | Reasoning |
|---|---|---|

| 2 | Ff | Same as 1 |
| 3 | FF or Ff | Unaffected; no affected offspring → cannot confirm |
| 4 | FF or Ff | Child of 1 & 2; unaffected; no affected offspring → cannot confirm |
| 5 | ff | Affected → homozygous recessive |
| 6 | ff | Affected → homozygous recessive |
| 7 | Ff | Unaffected, but has affected children (11 & 12) → must carry f |
| 8 | Ff | Unaffected, but has affected children (11 & 12) → must carry f |
| 9 | FF or Ff | Unaffected; no affected offspring |
| 10 | FF or Ff | Unaffected; no affected offspring |
| 11 | ff | Affected |
| 12 | ff | Affected |

## Question Two, Part B — Punnett Squares as Evidence

> 📝 **Tested in:** [Q2(b)](exam.md#q2b)
> **Also see:** [Pedigree Charts](study-guide.md#sg-q2a) · [Pedigree Strategy](study-guide.md#sg-pedigree-strategy)

### The Key Cross: Ff × Ff

|   | F  | f  |
|---|----|----|
| **F** | FF | Ff |
| **f** | Ff | ff |

**Result:** 1 FF : 2 Ff : 1 ff → **25% chance of an affected child each pregnancy**

### How to Use Punnett Squares as Evidence (not just a diagram)

For Q2(b), the Punnett square alone is not enough — you must *argue* with it:

1. **From parents (1 & 2):** Since 1 & 2 are unaffected but have affected children (5 & 6), both must carry an f allele → both are Ff. Individual 7 is their child → 7 could have inherited Ff (shown by the Punnett square cross Ff × Ff).

2. **From children (11 & 12):** Since 7 & 8 are unaffected but have two affected children, each must contribute an f allele → both 7 & 8 must be Ff.

**For Excellence:** Use BOTH directions of evidence — from parents (1 & 2) AND from children (11 & 12). One direction alone limits you to Merit.

## Question Two, Part C — Purpose of Genetic Tracking

> 📝 **Tested in:** [Q2(c)](exam.md#q2c)
> **Also see:** [Genetic Testing](study-guide.md#sg-testing) · [How to Write for Merit/Excellence](study-guide.md#sg-writing)

### Why Individual 4's Genotype Cannot Be Confirmed

- 4 is unaffected → has at least one F allele
- 4 is a child of 1 & 2 (both Ff) → could have inherited FF or Ff
- Children 9 & 10 are both unaffected → could be FF or Ff either way
- **Only if 3 & 4 have an affected child would we know both are Ff**

### Purpose of Tracking — Three Levels

| Level | What tracking tells you | Why it matters |
|---|---|---|
| **Individual 4** | Whether she is a carrier (Ff) or not (FF) | If Ff, she and 3 have a 25% chance per pregnancy of an affected child → informs family planning |
| **Children (9 & 10)** | If 4 is Ff, 9 & 10 may also be carriers | Helps them make informed decisions about their own future children |
| **Medical / societal** | Understanding inheritance patterns | Develop targeted treatments, advance genetic knowledge, enable genetic counselling |

**Grade tips:**
- **Achievement:** Identify that 10 could be FF or Ff; identify purpose for tracking
- **Merit:** Explain *why* 4's genotype cannot be confirmed (referencing 9 & 10); explain a purpose for tracking
- **Excellence:** Discuss purpose at *all three levels* — 4's parents, 4's own offspring, potential future offspring

## Question Three, Part A — Meiosis, Sexual Reproduction, Non-random Mating

> 📝 **Tested in:** [Q3(a)](exam.md#q3a)
> **Also see:** [Core Vocabulary](study-guide.md#sg-vocab) · [Meiosis vs Mitosis](study-guide.md#sg-meiosis)

### Meiosis

- Cell division producing **4 genetically non-identical** daughter cells (gametes)
- **Crossing over** (prophase I): homologous chromosomes exchange sections → new allele combinations
- **Independent assortment** (metaphase I): chromosomes align randomly → further allele variation in gametes
- Result: each gamete has a unique allele combination → f allele has a chance of being included

### Sexual Reproduction

- Two parents contribute genetic material; offspring receive one allele from each parent
- **Fertilisation**: fusion of sperm and egg (haploid + haploid → diploid)
- Even Ff × Ff parents (both unaffected) have a **25% chance** of producing an ff child
- The f allele is passed on invisibly through carrier parents

### Non-random Mating

- Mating that is **not** by random chance — individuals select mates for a reason (physical, genetic, cultural traits)
- In **small populations**: higher probability that two related individuals (both Ff) mate → inbreeding / mating with close relatives / second cousins
- Increases the chance that two f-carrying gametes combine → f allele persists or increases

### Linking All Three for Excellence

> Meiosis generates gametes that may carry f → sexual reproduction combines two gametes (both possibly carrying f) from Ff parents → non-random mating in small populations increases the likelihood that two f-carrying gametes meet → the f allele persists and may increase in the gene pool.

**Grade tips:**
- **Achievement:** Define meiosis, sexual reproduction, non-random mating, fertilisation; note crossing over or independent assortment; note two carriers can produce affected offspring
- **Merit:** Explain *how* meiosis (crossing over OR independent assortment) passes f; explain how carriers pass f via sexual reproduction; explain non-random mating in small populations
- **Excellence:** Link all three mechanisms together in one continuous explanation showing how they collectively keep the f allele in the population

## Question Three, Part B — f Allele Frequency in the Population

> 📝 **Tested in:** [Q3(b)](exam.md#q3b)
> **Also see:** [Allele Frequency Concepts](study-guide.md#sg-allele-freq) · [Genetic Testing](study-guide.md#sg-testing) · [Core Vocabulary](study-guide.md#sg-vocab)

### Why the f Allele May INCREASE

**Heterozygote advantage:**
- f allele is disadvantageous in ff individuals (cystic fibrosis)
- But neither advantageous nor disadvantageous in Ff individuals
- Ff individuals may have increased resistance to infectious diseases (e.g. cholera, typhoid)
- If this improves reproductive success → more Ff survive and reproduce → f allele frequency rises

**Genetic drift (small populations):**
- By random chance, heterozygotes may mate together more often in a small gene pool
- f allele frequency rises without any selective advantage

### Why the f Allele May DECREASE

**Genetic testing:**
- Increased availability of genetic testing means prospective parents can screen for the f allele
- If f is detected, they may not implant an embryo (IVF) or may terminate a pregnancy
- Over generations, f allele frequency could decline — especially in populations with access to this technology

### Key Excellence Concept — More f Alleles ≠ More CF Phenotype

> The dominant F allele **completely masks** the recessive f allele in heterozygotes.

If the population shifts from FF to Ff individuals:
- Number of f alleles **increases** (each Ff person carries one f)
- Number of ff individuals (who show CF) does **not** increase — may even decrease
- Because Ff individuals are phenotypically normal — they never develop cystic fibrosis

**Example:** If there are fewer FF and more Ff individuals, f allele frequency rises, but CF phenotype frequency stays the same (only ff individuals are affected).

**Grade tips:**
- **Achievement:** Define population; state f allele will increase due to heterozygotes; identify f as disadvantageous in ff but neutral in Ff
- **Merit:** Explain a logical scenario for increase, decrease, or stable; explain *why* f allele can increase without CF phenotype increasing
- **Excellence:** Comprehensively discuss AND clearly justify why rising f allele frequency does not necessarily mean rising CF phenotype frequency

## Common Mistakes — What Not Achieved Candidates Did

> 📝 **Relevant to:** All questions

These are exact errors from the 2025 assessment report:

1. **"gene" and "allele" used interchangeably** — most damaging; limits you to Achievement at best
2. **"genotype" and "phenotype" confused** — e.g. "the genotype of the individual is cystic fibrosis"

4. **Genotypes written with only one allele** — write "FF" or "Ff", never just "F"
5. **Restating the question** — copying words from the question without adding biological explanation
6. **Copying the stimulus** — using the exam paper's own sentences without applying biological knowledge
7. **Leaving questions blank** — always attempt; partial marks exist at every level
8. **Not linking DNA → chromosome → gene → allele** — these must be connected, not listed separately

> 📝 **Most relevant to:** [Q2(c)](exam.md#q2c) · [Q3(a)](exam.md#q3a) · [Q3(b)](exam.md#q3b)

| Word | What it requires |
|---|---|
| *Define* | One-sentence precise definition |
| *Describe* | What it is + key features |
| *Explain* | What + **WHY** it happens |
| *Discuss* | Multiple angles; consider different possibilities |

## B. Pedigree Reading — Step-by-Step Strategy

> 📝 **Most relevant to:** [Q2(a)(i)](exam.md#q2ai) · [Q2(a)(ii)](exam.md#q2aii) · [Q2(b)](exam.md#q2b) · [Q2(c)](exam.md#q2c)

1. Find all **affected individuals** (shaded) → their genotype is **ff**
2. Work backwards: affected individual's parents must each carry at least one f → both parents are **Ff**
3. Check unaffected siblings of an ff individual → *could be* FF or Ff
4. Work forwards: if an unaffected person has an affected child → they must be **Ff**
5. If no affected children → genotype **cannot be confirmed** (could be FF or Ff)

> ⚠️ **Never write "Individual X is FF"** unless you can prove they cannot carry an f allele. If there is any doubt, write **"FF or Ff"**.

## C. Meiosis vs Mitosis — Know the Difference

> 📝 **Most relevant to:** [Q3(a)](exam.md#q3a)

| | Meiosis | Mitosis |
|---|---|---|
| Purpose | Produce gametes (sex cells) | Growth, repair, replacement |
| Divisions | 2 | 1 |
| Daughter cells | 4, haploid (n) | 2, diploid (2n) |
| Genetic identity | Non-identical (crossing over + independent assortment) | Identical |
| Where | Gonads (ovaries, testes) | Throughout body |

> Only **meiosis** is relevant to 92022 — it's the process that creates gametes carrying alleles to offspring.

## D. Allele Frequency Concepts — Population Thinking

> 📝 **Most relevant to:** [Q3(b)](exam.md#q3b)

- **Allele frequency** = how common an allele is across all individuals in a population
- The f allele exists mostly **hidden inside Ff heterozygotes** — these individuals are phenotypically normal and reproduce freely
- Natural selection acts on **phenotype**, not genotype — since Ff looks normal, the f allele is "invisible" to selection pressure
- This is why the f allele persists despite causing a serious disease when homozygous

**Heterozygote advantage** (balanced polymorphism):
- If Ff individuals have higher survival/reproductive success than FF or ff (e.g. disease resistance)
- Then both F and f are maintained in the population — neither disappears completely
